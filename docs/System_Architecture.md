# Mathematics Assessment System (MAS)

Version: 0.1

---

## 1. Project Objective

MAS is an Excel-based assessment system designed for High School Mathematics Departments.

The objectives are:

- Standardize assessment
- Reduce teacher workload
- Ensure fairness across classes
- Generate real-time dashboards
- Support ability grouping
- Support student transfer recommendation

---

## 2. Core Principles

The system follows six principles.

### 1. Single Source of Truth

Every piece of information only exists once.

Student data

↓

Assessment

↓

Dashboard

↓

Reports

All generated from one database.

---

### 2. Dynamic Configuration

No value is hard coded.

Everything can be modified in

Settings

without changing formulas.

---

### 3. Transparency

All formulas are visible.

Formula cells are protected.

Teachers may inspect calculations.

---

### 4. Ease of Use

Teachers should

never

edit formulas.

Only choose

Dropdown

or

Input Score.

---

### 5. Automation

Everything should calculate automatically.

No manual statistics.

No manual ranking.

No manual transfer list.

---

### 6. Future Ready

Compatible with

Excel 365

Power Query

Power Pivot

Power BI

Microsoft Teams

Microsoft Forms
