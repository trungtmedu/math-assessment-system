# Mathematics Assessment System (MAS)

Mathematics Assessment System (MAS) is an open-source Excel-based assessment and learning analytics system designed for high school Mathematics departments.

The project aims to support:

* Standards-based assessment
* Ability-grouped classes (Foundation / Core / Advanced)
* Student progress monitoring
* Teacher dashboards
* Department-level analytics
* Promotion and transfer recommendations
* Reporting and documentation

## Target Users

* Mathematics Teachers
* Department Heads
* School Leaders

## Technology

* Microsoft Excel 365
* Power Query
* Power Pivot
* Dynamic Arrays
* Pivot Tables
* Pivot Charts

No VBA is required in Version 1.0.
